## DiscordCard Element

Shows a Discord server (icon, name, online/member counters, badges, description and banner) with a **Join** button, so users can join it without leaving the UI.  
Everything is read from the invite, so you only need to give it an invite link.

## How it works

1. Asks the public Discord API about the invite: name, description, icon, banner, member count, online count and badges.
2. Downloads the icon and the banner from the Discord CDN. Only real PNG files are accepted, error pages are ignored.
3. **Join** first tries to open the invite in the Discord desktop app, which shows the usual "Join server" prompt. If the app is not open, it copies the invite link to the clipboard and shows a notification.
4. **Copy link** always copies the link.

The banner is full-width, touches the edges of the card and fades into it. In `"Auto"` it tries the server profile banner, then the invite splash, then the normal server banner. If the server has none of them, the server brand color is used. If the banner is not the one you see in Discord, try the other sources.

## Examples

### Compact card

```luau
Tab:DiscordCard({
    Invite = "yourcode",
    ShowBanner = false,
    ShowDescription = false,
    ShowBadges = false,
    ShowCopyButton = false,
})
```

```luau
Tab:DiscordCard({
    Invite = "yourcode",
    OnlineFormat = "{count} playing now",
    MembersFormat = "{count} in the community",
    OnlineColor = Color3.fromRGB(88, 101, 242),
    ShortNumbers = true,
})
```

### Round icon with the dot on the top

```luau
Tab:DiscordCard({
    Invite = "yourcode",
    IconShape = "Circle",
    StatusDotPosition = "TopRight",
    StatusDotAlways = true,
})
```

### Your own tags

```luau
Tab:DiscordCard({
    Invite = "yourcode",
    Badges = { Community = false },
    Tags = {
        { Title = "Official", Color = Color3.fromHex("#30ff6a") },
    },
})
```

## Troubleshooting

- **No images, only text:** the executor probably lacks `writefile` or `getcustomasset`, or the HTTP request failed.
- **The banner is not the one shown in Discord:** change `BannerSource` (`"Profile"`, `"Splash"`, `"Banner"` or `"Icon"`).
- **Empty space next to the Join text:** the `ButtonIcon` asset can't be loaded (for example a Decal id instead of an Image id, or a private asset). A built-in icon replaces it after a few seconds. Use an Image asset id to use your own.
- **"Invite invalid or expired":** use a permanent invite, since temporary invites stop working when they expire.
